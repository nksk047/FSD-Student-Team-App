# Student Team Members Management App

This full-stack application allows teams to add, view, and manage student team members.

## 🚀 Technologies Used

- **Frontend**: React.js
- **Backend**: Node.js + Express.js
- **Database**: MongoDB (with MongoDB Compass)
- **File Uploads**: Multer
- **Styling**: CSS
